# @vibeinging/dsh-desktop-shell

Desktop shell integrations for DSH. This bundle's host half is inert; its client half
promotes the dshmarket plugin market to a first-class home panel (beside 插件) and
retires the market's settings section, using dshmarket's own host-integration service
(`market.render()` / `market.setSettingsVisible(false)`).

Peer pins: `@deepseek-ai/dsh-client-ui-slots@0.2.0-rc.1`, `dshmarket@1.66.3`.
